# Cơ thể của em 🍭

Trò chơi đoán từ cho học sinh Lạc Hồng: tìm 3 chữ cái còn thiếu trong tên các bộ phận bên ngoài cơ thể (mũi, miệng, tai, mắt, bàn tay…).

## Cách chơi
1. Nhập tên học sinh vào ô **Nhập tên em…** rồi bấm **Thêm**.
2. Bạn đến lượt bấm các chữ cái để điền vào 3 ô trống, rồi bấm **Kiểm tra**.
3. Đoán đúng được 1 cây kẹo mút 🍭. Bấm **Lượt tiếp theo** để chuyển sang bạn kế tiếp.
4. **Màn hình đêm / Màn hình ngày**: đổi giao diện tối hoặc sáng.
5. **Dừng & xem kết quả**: xem ai có nhiều kẹo mút nhất.
6. **Chơi lại từ đầu**: xoá kẹo (có thể giữ hoặc xoá tên) để chơi ván mới.

## Chạy trò chơi
Mở file `index.html` bằng trình duyệt, hoặc bật GitHub Pages (Settings → Pages → Deploy from branch `main`, thư mục `/ (root)`).
